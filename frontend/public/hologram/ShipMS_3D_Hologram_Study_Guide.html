1. Overview & Objective (परियोजना का परिचय एवं उद्देश्य)

Yeh project ek Futuristic Full-Screen 3D Hologram Application hai, jise Three.js, Custom WebGL/GLSL Shaders aur UnrealBloom Post-Processing ke zariye banaya gaya hai. Iska mukhya aakarshan screen ke center mein sthit ek vishal aur highly-detailed Ocean-Going 3D Container Vessel (ShipMS / "OCEAN EXPLORER") hai, jo glowing holographic emitter platform ke upar 3D space mein float aur rotate karta hai.

🎯 Mukhya Visheshatayein (Key Features):
  • 100% Real Interactive 3D: Kisi bhi flat image ka upayog nahi kiya gaya; ship ka har ek hissa (hull, containers, bridge, masts, radar, lifeboats) pure 3D geometry se bana hai.
  • Futuristic Hologram Visuals: Electric cyan glowing wireframes, semi-transparent body, moving vertical scanlines, aur Fresnel rim lighting.
  • Hologram Base Platform: Rotating concentric laser rings, radial degree coordinates, aur ek upward curved projection grid funnel jo ship ke hull ko cradle karta hai.
  • Real-Time "HOLOGRAM BRIGHTNESS" Volume Slider: Ship ke glow/bloom ko 0% se 100% tak live adjust karne ki suvidha taaki 3D model ke sabhi details hamesha saaf aur crisp dikhein.

2. Technologies & System Architecture (तकनीकी संरचना)

Is project ko modern web graphics standards ka upayog karke build kiya gaya hai. Isme kisi external backend ya heavy build-tool ki zaroorat nahi hai—yeh 100% standalone aur offline chalta hai.

📦 1. Three.js (r128) & WebGL

  • WebGLRenderer: High-performance hardware accelerated GPU rendering with ACESFilmic tone mapping.
  • PerspectiveCamera: 45° FOV camera positioned at 3/4 isometric perspective `(34, 18, 38)`.
  • Scene Graph & Groups: Hierarchical structure dividing Hull, Cargo, Bridge, Platform, and Particles.

⚡ 2. Custom GLSL Shaders

  • Vertex Shader: World matrix, view vectors, aur normals transform karta hai.
  • Fragment Shader: Mathematical Fresnel glow, sine wave scanlines, aur radar sweep waves generate karta hai.
  • Additive Blending: Laser light particles aur wireframes ko intense glow deta hai.

✨ 3. Post-Processing Pipeline

  • EffectComposer: Multi-pass rendering buffer pipeline.
  • RenderPass: Base scene ko capture karta hai.
  • UnrealBloomPass: Radiant laser neon glow create karta hai without washing out darks.

🔊 4. Web Audio API & Controls

  • OrbitControls: Smooth mouse/touch drag 360° rotation with damping.
  • Web Audio Synthesizer: Zero external audio files; pure JavaScript mathematical oscillators generate sci-fi hums and clicks.

Dual-Layer Rendering Technique (होलोग्राम वायरफ्रेम + बॉडी कैसे बना):

Har ek 3D object ko 2 layers mein render kiya gaya hai: 

// 1. Body layer: Semi-transparent holographic material with Fresnel glow
const bodyMat = this.shaders.createHologramMaterial(bodyMatOptions);
const mesh = new THREE.Mesh(geometry, bodyMat);
group.add(mesh);

// 2. Edge layer: Crisp, radiant cyan wireframe outlines
const edges = new THREE.EdgesGeometry(geometry, 20);
const lineMat = this.shaders.createWireframeEdgeMaterial(edgeColor, edgeOpacity);
const line = new THREE.LineSegments(edges, lineMat);
group.add(line);

4. Hologram Platform & Projector Grid (`js/platform-builder.js`)

Reference image ke anusaar ship ke neeche ek futuristic circular holographic platform create kiya gaya hai jisme 4 core elements hain:

  • Concentric Counter-Rotating Rings: 6 alag-alag radius ke THREE.TorusGeometry rings jo alag-alag speed aur direction mein ghoomte hain. Inpar 64 radial azimuth degree measurement ticks bane hain.
  • Circular Coordinate Grid Disc: Canvas API se generate kiya gaya 1024x1024 texture jisme degree markings (0°, 45°, 90°, 180°, 270°, 360°) aur radial coordinate spokes hain.
  • Curved Hyperbolic Projection Funnel: Base emitter se ship ke hull tak uthne wala ek upward flaring wireframe grid cone jo ship ko laser se project karne ka visual illusion deta hai: 
    const rX = 2.5 + Math.pow(v, 1.6) * 12.0; // Parabolic expansion along beam width
const rZ = 2.5 + Math.pow(v, 1.6) * 24.0; // Parabolic expansion along ship length
  • Rising Photon Particles: 450+ energy motes jo base se nikal kar ship ke charon taraf upward swirl physics ke sath drift karte hain.

5. Holographic GLSL Shader Math (`js/hologram-shaders.js`)

Hologram ka visual magic custom GLSL (OpenGL Shading Language) fragment shaders ke mathematical calculations se banta hai:

A. Fresnel Rim Glow Formula:

Fresnel effect se object ke kinaron (grazing angles) par light tez glow karti hai aur seedhe dekhne par semi-transparent rehti hai: 

float NdotV = max(dot(normal, viewDir), 0.0);
float fresnel = pow(1.0 - NdotV, uFresnelPower) * uFresnelIntensity;

B. Animated Scanlines & Radar Sweep:

Ship ke vertical Y-axis par chalne wali moving holographic scanlines: 

// Vertical fine scanlines
float scanline = sin(vWorldPosition.y * uScanlineFreq - uTime * uScanlineSpeed) * 0.5 + 0.5;
scanline = pow(scanline, 2.0) * 0.3;

// Broad upward sweeping radar pulse
float sweepWave = sin(vWorldPosition.y * 0.25 - uTime * 1.8);
float sweep = smoothstep(0.7, 1.0, sweepWave) * 0.4;

6. Real-Time "HOLOGRAM BRIGHTNESS" Volume Slider (`js/main.js`)

User ke control ke liye ek dedicated cyberpunk volume slider add kiya gaya hai jo bina kisi lag ke Three.js Post-Processing Bloom aur Shader Uniforms ko real-time adjust karta hai:

🎛️ Mathematical Interpolation Logic (setHologramBrightness):
setHologramBrightness(normVal) { // normVal = 0.0 to 1.0 (0% to 100%)
  // 1. Scale Bloom Strength & Threshold (Kam glow par 3D details sharp rehti hain)
  this.bloomPass.strength = 0.05 + Math.pow(normVal, 1.3) * 2.15;
  this.bloomPass.threshold = 0.42 - normVal * 0.30;

  // 2. Scale Ship Material Shaders
  for (const mat of this.shipBuilder.animatedMaterials) {
    mat.uniforms.uFresnelIntensity.value = 0.35 + normVal * 2.5;
    mat.uniforms.uInnerGlow.value = 0.05 + normVal * 0.55;
    mat.uniforms.uOpacity.value = 0.22 + normVal * 0.45;
  }
}

How 3D-to-2D Coordinate Tracking Works (गणितीय तकनीक):

// 1. Transform local 3D anchor vector to world space (accounts for ship float/pitch/roll)
tempVec.copy(sec.pos);
sec.group.localToWorld(tempVec);

// 2. Project 3D vector to Normalized Device Coordinates (NDC)
tempVec.project(this.camera);

// 3. Convert NDC (-1 to +1) to 2D Screen pixel coordinates
const sx = (tempVec.x * 0.5 + 0.5) * window.innerWidth;
const sy = (-tempVec.y * 0.5 + 0.5) * window.innerHeight;

// 4. Render SVG laser leader line & reticle
item.line.setAttribute('points', `\${sx},\${sy} \${elbowX},\${elbowY} \${connX},\${connY}`);
